ECO 625: Data Methods in Economics

Fall 2024

Coursework

This project analyzes CPS data to evaluate the relationship between educational attainment and earned income using multivariable regression modeling. I selected it because it demonstrates applied econometric analysis, coefficient interpretation, and sensitivity testing using real national survey data.

Learning Objectives

  1. Describe the process of data analysis.
  2. Describe common data issues.
  3. Recall basic syntax of Base SAS data steps and procedures.
  4. Utilize SAS software within SAS Studio to manipulate data.
  5. Produce descriptive statistics and graphs using SAS software.
  6. Analyze data using hypotheses tests and simple and multiple regression using SAS software.

Reflection

ECO 625 helped me deepen my understanding of programming by introducing a new language while also showing me how much carries across languages once the underlying logic is understood. Learning SAS was useful not only because it gave me experience with industry-standard software, but also because it reinforced the fact that prior programming experience can transfer into new environments. That made me more confident in my ability to learn unfamiliar tools without starting from zero each time.

The course also helped move economics and statistics from a more theoretical level into a clearly applied exercise. The project focused on analyzing and hypothesis testing data related to the value of higher education on earnings, which made the work feel immediate and personally relevant. Writing the results while moving through my own degree path gave the project a different kind of weight, because I was not just studying the economic case for education in the abstract. I was working through evidence that spoke directly to the value of my own continued education and professional transition.
