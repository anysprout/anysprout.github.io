ISM 645: Principles of Predictive Analytics

Fall 2024

Coursework

This project integrates 2023 flight data with hourly weather observations to analyze delay patterns at RDU Airport. I selected it because it demonstrates large-scale data cleaning, feature engineering, and applied statistical modeling within a real operational context.

Portfolio Assignment: View on GitHub →

Learning Objectives

  • Demonstrate an understanding of the principles of predictive analytics.
  • Identify, design, and assess different predictive analytics methodologies.
  • Prepare and formulate data collection, preprocessing, and exploration for analytical purposes.
  • Apply and assess different predictive analytic models and techniques.
  • Evaluate organizational implications of the use and implementation of predictive analytics.
  • Demonstrate proficiency in the use of analytics software.

Reflection

ISM 645 helped me build a stronger foundation in the practical side of analytics. I learned how to obtain relevant data, clean it in a transparent way, and structure code so the workflow can continue as new data becomes available. That process made me more disciplined about data hygiene and more aware of how much analytical quality depends on the steps that come before modeling.

The course also gave me more experience writing functions for analysis and visualization, which made it easier to work through large datasets without losing track of the logic behind the results. More than anything, this project helped me get better at extracting meaningful trends from messy, high-volume data and presenting them in a way that others can follow. That is a skill I expect to keep using in both research and professional settings.
